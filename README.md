# Portfolio Website Template

A modern, customizable portfolio website built with **React** and **Vite**. This template is open-source and can be used by anyone to showcase their projects, skills, experience, and contact information.

## Features

- **React 19 & Vite** f
- **Fully Customizable**: Simple component structure to quickly swap out text, images, and project details.
- **Responsive Layout**: Designed to look great on desktop, tablet, and mobile devices.
- **Open-Source Template**: Free to clone, fork, and adapt for your own personal portfolio.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CTigranMM/Portfolio-Template.git
   cd Portfolio-Template
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` to preview the site.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production build files will be generated in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, Netlify, or any static hosting service.

## Usage as a Template

Feel free to fork or clone this repository and customize it for your personal portfolio:
1. Update `src/App.jsx` and components with your own information, skills, and projects.
2. Replace assets in `src/assets/` or `public/` with your own images.
3. Update metadata in `index.html` (title, favicon, meta tags).
